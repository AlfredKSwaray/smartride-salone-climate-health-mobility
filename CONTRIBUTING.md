# Contributing to SMARTRIDE SALONE

Thank you for your interest in contributing to SMARTRIDE SALONE!

## How to Contribute

1. Fork the repository on GitHub
2. Make your changes to the code
3. Test your changes locally by opening index.html in a browser
4. Submit a Pull Request describing what you changed and why

## Types of Contributions Welcome

- Bug fixes
- New map features
- Improved flood data integration
- Better mobile responsiveness
- Translations into local Sierra Leone languages
- Documentation improvements

## Code of Conduct

Please be respectful and constructive in all interactions.

## Questions?

Open a GitHub Issue and we will respond as soon as possible.

Thank you for helping improve healthcare access in Sierra Leone!
