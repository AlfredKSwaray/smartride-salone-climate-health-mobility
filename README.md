# smartride-salone-climate-health-mobility
SMARTRIDE SALONE is a climate-resilient mobility intelligence platform designed to improve access to healthcare for vulnerable communities, especially children, in Sierra Leone.

The system uses GPS tracking and route data to map transportation conditions and identify safer, more efficient routes during climate-related disruptions such as flooding and heavy rainfall. By connecting mobility data with real-world accessibility challenges, the platform aims to reduce delays in reaching healthcare services and support emergency response planning. 
The vision is to build a scalable, data-driven mobility system that enhances climate resilience and ensures equitable access to healthcare services across underserved communities. This project is being developed with an open and collaborative approach, with the goal of making mobility data accessible for public good and supporting innovation in climate resilience and healthcare access.
