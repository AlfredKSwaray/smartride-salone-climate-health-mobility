# Code of Conduct

## Our Pledge

We are committed to making participation in SMARTRIDE SALONE a respectful and inclusive experience for everyone.

## Our Standards

- Be kind and respectful to all contributors
- Focus on what is best for the communities we serve in Sierra Leone
- Accept constructive feedback gracefully
- Show empathy towards other community members

## Our Responsibilities

Project maintainers will remove, edit, or reject contributions that do not align with this Code of Conduct.

## Scope

This Code of Conduct applies to all project spaces including GitHub, email, and any community events.

## Contact

If you experience any issues, please open a GitHub Issue.
